readme.txt

A tiny, independently written alternative to Litterbox. No signup. No library. No algorithm asking how that made you feel.

Files disappear after your chosen lifetime. Downloads stop at expiry; disk cleanup runs every minute. Downloads save as attachments.

This is temporary public hosting. Links are unlisted, not private. Keep personal documents and secrets elsewhere. No backups of uploads; files may disappear early if the service fails.

Only upload files you have permission to share. Report abuse with the file URL to slop@freifick.net.

IP addresses are used in memory for hourly upload limits; the app does not log uploads or filenames. The reverse proxy has no access log for this service.

for terminal dwellers

Multipart API, familiar field names. The response is a plain URL:

curl -F reqtype=fileupload -F time=24h \
  -F fileToUpload=@your-file.zip \
  https://mayfly.freifick.net/resources/internals/api.php

Use POST /api/upload with the same fields for JSON with url, delete_url, expires, name and size. Delete early with curl -X DELETE 'YOUR_DELETE_URL'. One file per request. No URL imports.
