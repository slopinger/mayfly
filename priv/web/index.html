service notes

Files expire after your chosen lifetime and may disappear early if the service fails. Links are unlisted, not private. Keep secrets elsewhere. Downloads save as attachments.

20 upload attempts per hour per IP. IP rate data stays in memory for up to an hour. No upload access logs, cookies or backups.

Only share files you have permission to upload. Report abuse with the file URL to slop@freifick.net.
